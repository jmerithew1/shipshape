Ship SDK — Authorization Code + PKCE

A single-page app that logs in with PKCE (generated here, in the browser, with Web Crypto), stores the tokens in LocalStorageTokenStore, and lists your documents through @ship/sdk. No client secret is involved — the code verifier is the proof.

Connection

Finish a redirect by hand

Ship's /oauth/authorize returns JSON consent context — rendering the consent screen is the first-party web app's job, not this demo's. If you approved the grant elsewhere, paste the full redirect URL you were sent to and this page will finish the exchange.
