#     2026-08-03 "Render Starter tier").

#     were on-push, contradicting our "no green CI, no deploy" claim. With
#     this flag off, the ONLY push-driven deploy path is the CI deploy job
#     that runs after checks + secret-scan pass (.github/workflows/ci.yml).
#   * env_vars += ANTHROPIC_API_KEY, LANGSMITH_TRACING/API_KEY/PROJECT,
#     FLEETGRAPH_SWEEP_MINUTES — the agent's model + tracing config. Values
#     arrive via sensitive TF_VAR_* at plan time; they appear below only as
#     "(sensitive value)" and are never committed (same posture as
#     DATABASE_URL).
