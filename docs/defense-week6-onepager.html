Architecture defense · Mon Aug 11 · 13:00 CT · James Merithew

SHIP → PLATFORM

The grade is one loop: a stranger installs the SDK and gets a verified, signed webhook in their terminal. Every decision below exists to make that loop short and provable.

TTFE CI <60s HUMAN ≤30min FLAKE 0% / 20 runs SPEC PARITY 100% PLATFORM LLM CALLS 0
01

One gate, one shape, one spec

OAuth tokens flow through the same validator that already guards the API. Every failure is one ApiError shape. The OpenAPI spec is generated from the routes — it structurally cannot lie — and the SDK is diffed against it in CI. Hand-rolled grants because no library implements the Device Grant: the hard part was ours either way.

02

One Postgres table is the whole webhook system

The required retry ladder forces persistence anyway — so the persistence is the queue. DLQ is a status. Replay keeps the original idempotency key. No broker: single-instance deploy makes in-process delivery correct, and the queue-backed deliverer stays a drop-in behind the same interface. webhooks tail works like stripe listen: the CLI verifies the HMAC locally — the key never leaves the client.

03

The agent walks in the front door

FleetGraph trades its private DB pool for the public SDK, behind a flag. Same scopes, same rate limits, same audit trail as a stranger — the audit rows are the proof the platform is real. Cost shape unchanged: zero platform LLM calls, one call per agent turn, token volume verified before/after in LangSmith.

04

Terraform is the recipe; Render is the kitchen

Three declared resources are the whole deployment — terraform apply from a clean machine is the deploy, and destroy-and-redeploy is already proven and graded. IAM least-privilege runs the real secrets code path on a terraform-managed scratch: admin → one ssm:GetParameter ARN, allow proven, deny proven, zero contact with the graded deployment.

  • -/+ means replace. Find the attribute that forces it, then walk right along the spine.
  • ~ on env vars still deploys. DATABASE_URL changes because postgres changed, not because someone typed it.
  • starter → free looks harmless. Idling silently kills the cron and the webhook poller.
05

Deliberately not built

No message broker (single instance; the interface keeps the swap open) · no service-layer refactor (week-eating, invisible to graders) · no OAuth library (they skip the part we must build) · no ECS side-stack (we defend the deployment that serves you) · no platform AI (the brief itself calls it scope creep). Scope was chosen, not defaulted into.
