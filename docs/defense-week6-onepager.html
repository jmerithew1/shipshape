Architecture defense · Mon Aug 11 · 1:00 pm CT

Ship stops being an app and becomes a platform.

The grade is one loop: a stranger installs the SDK and has a verified, signed webhook in their terminal. Everything below exists to make that loop short and provable.

01

One gate, one shape, one spec

OAuth tokens flow through the same validator that already guards the API. Every failure is one ApiError shape. The OpenAPI spec is generated from the routes — it structurally cannot lie — and the SDK is diffed against it in CI.

02

One Postgres table is the whole webhook system

The required retry ladder forces persistence anyway — so the persistence is the queue. DLQ is a status. Replay keeps the original idempotency key. The queue-backed deliverer stays a drop-in behind the same interface.

03

The agent walks in the front door

FleetGraph trades its private DB pool for the public SDK, behind a flag. Same scopes, same rate limits, same audit trail as a stranger — the audit rows are the proof the platform is real. Cost unchanged: the platform makes zero LLM calls.

04

Terraform is the recipe; Render is the kitchen

Three declared resources are the whole deployment — terraform apply from a clean machine is the deploy, and destroy-and-redeploy is already proven. IAM least-privilege runs the real secrets code path on a terraform-managed scratch: admin → one ssm:GetParameter ARN, allow proven, deny proven.

  • -/+ means replace. Find the attribute that forces it, then walk right along the spine.
  • ~ on env vars still deploys. DATABASE_URL changes because postgres changed, not because someone typed it.
  • starter → free looks harmless. Idling silently kills the cron and the webhook poller.
05

Deliberately not built

No message broker (single instance; the interface keeps the swap open) · no service-layer refactor (week-eating, invisible to graders) · no OAuth library (they skip the part we must build) · no ECS side-stack (we defend the deployment that serves you) · no platform AI (the brief itself calls it scope creep).

If pushed on risk: the de-scope ladder is pre-committed — PKCE-only with loopback CLI login, then existing API tokens driving the drill. Ledger: docs/week6-requirements.md · decisions + rejected alternatives: DECISIONS.md
