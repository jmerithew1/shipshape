FleetGraph

Ship shows you what's happening. FleetGraph tells you what's wrong — especially when the signal is silence.

Design checkpoint — no agent code yet, by design. Every claim below is labeled in FLEETGRAPH.md.
1

A coordinator, not a dashboard

The worst problems emit no events — an issue nobody touches never pings anyone. FleetGraph notices, drafts the fix, and never rewrites your plan without asking.

Acts on its own

Surface findings, post attributed comments, answer chat — additive, visible, reversible by ignoring

Asks first

Anything that rewrites a person's plan — reassign, move, change state or dates

Never

Delete, auth changes, outside communication — the executor has no such verbs. Not a prompt rule: the code physically can't.

Proactive mode and chat are the same graph — same reasoning, same safety gates. Cheap checks run first; the AI only wakes when they fire. A healthy project costs $0.

3

Events for what happens. A clock for what doesn't.

Graded test: create an unassigned issue, start the stopwatch. Card visible in ≈ 2–3 minutes against a 5-minute goal.

90s grace
30s settle
~15s
buffer to the 5:00 goal
0:00 issue created≈2:30 card visible ▲5:00 goal

Why wait 90 seconds? Every new issue is born "Untitled" and empty for a few seconds while someone types. Firing instantly would nag people mid-keystroke — the grace window is printed on the card, so the demo explains itself.

We attacked this design before writing code

Three scoping lenses, then a blind red-team pass given only the spec. It found three real problems in our own infrastructure — verified, then folded into the plan.
