GFA · Week 5 · Architecture Defense — Ship Platform

FleetGraph

Ship shows you what's happening. FleetGraph tells you what's wrong — especially when the signal is silence.

Tuesday: an issue goes quiet. No event fires, no dashboard turns red. Friday: it's the reason the week slips — and everyone finds out at the retro. Every tool on the market shows you the activity. Nothing watches the silence.

Design checkpoint — no agent code yet, by design. Every claim below is labeled in FLEETGRAPH.md.
01
How we decided · three-lens scoping

A coordinator, not a dashboard

FleetGraph notices what's drifting, drafts the fix, and never rewrites your plan without asking.

Acts alone

Surface findings, post attributed comments, answer chat — additive, visible, reversible by ignoring

Asks first

Anything that rewrites a person's plan — reassign, move, change state or dates

Never

Delete, auth changes, outside communication — the executor has no such verbs. Not a prompt rule: the code physically can't.

The decision process: every scope choice went through three lenses — economics (is it worth building?), psychology (will a human want it?), technology (does the data exist?). That's how 7 discovered use cases became 5 built ones: the graded table requires a real trace per row, so we defined exactly what we can prove.

03
How we decided · psychology lens × the data model

Events for what happens. A clock for what doesn't.

Graded test: create an unassigned issue, start the stopwatch. Card visible in ≈ 2–3 minutes against a 5-minute goal.

Why wait 90 seconds? The psychology lens collided with a data-model fact: every new issue is born "Untitled" and empty while someone types. An agent that fires instantly nags people mid-keystroke — so we spend 90 of our 300 seconds on manners, and print the grace window on the card so the demo explains itself.

04
How we decided · game theory + behavioral economics

It earns the right to interrupt

Alerting is a repeated game: every false alarm spends trust the agent never gets back. Competitors use static thresholds set by an admin. FleetGraph keeps score of its own usefulness — per person — and interrupts less when it's been wrong.

The crying-wolf score (per person, per finding type)

The agent tracks whether each person actually acts on its findings, forgets old evidence on purpose, and raises its own bar before interrupting someone it's been wasting:

scores are per-type, not per-person
  • defaults — multi-issue proposals arrive pre-checked: agreeing is one click, editing is easy, all-or-nothing is never forced.
  • friction asymmetry — Still on it is the cheapest button on the card: one tap, resets the clock, notifies nobody. Clearing a false alarm must cost less than learning to ignore the agent.
  • loss framing — cards say "3 issues won't make Friday," not "completion rate 20% at 70% elapsed."
  • incentive compatibility — report a slip before the detector finds it, and it's a recalibration, not a failure. Hiding bad news stops paying.

The decision process: we treated notifications as a mechanism-design problem, not a settings page. Critical severity always gets through; the math has guards so the agent can never talk itself into permanent silence.

05
How we decided · blind red team

We attacked this design before writing code

A critic with zero context got the spec and orders to break it. It found three real problems in our own infrastructure — each one verified against the repo, then folded into the plan.

✕

A Week-4 deploy defect would have silently eaten the agent's database tables on Render — fix is scheduled Day 1, before any agent code.

✕

Deploy-on-push contradicted our own "CI-gated deploys" claim — now: no green CI, no deploy.

✕

The rebuild-from-scratch test would have destroyed the demo data with it — repopulation is now a scripted part of the proof.

Every decision logged — with the alternative we rejected written next to it. The same process reviewed outside proposals: ten game-theory features were pitched; three survived the feasibility check against our own schema. Saying no, with receipts, is the discipline this week graded.
